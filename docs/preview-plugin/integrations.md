## Quick Integration

Requires three main steps:
1. Implement `BPI_ModularCharacterPreview` on your Character and return Main Mesh, Follower Meshes, Face Mesh, and Groom Components in `GetMeshes`.
2. Add the preview component (`BPC_ModularCharacterPreview`) to the Player Controller.
3. Add the provided preview widget (`W_ModularCharacterPreview`) to any UI container (inventory or equipment screens).

Character setup:
No additional tags are required.

See the Installation page for the step-by-step guide with images.
